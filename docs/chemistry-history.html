About this experiment

This version uses the preferred chemistry print with a subtle variation in local emulsion sensitivity. Spectral transmission, stochastic grain activation, developer diffusion, finite couplers, and diffuse paper reflection run in a browser worker. The graphs show computed values at your chosen pixel.

The browser and Python implementations use independent random realizations. Material constants are experimental. The preview renders at the selected resolution. Open the process whiteboard.
